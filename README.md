# GymManagerWebsite
Bu proje, 2025–2026 Güz Dönemi Web Programlama dersi kapsamında geliştirilmiş bir Spor Salonu (Fitness Center) Yönetim ve Randevu Sistemidir. Proje, ASP.NET Core MVC mimarisi kullanılarak gerçek hayattaki bir spor salonunun; üyelerini, antrenörlerini, hizmetlerini ve randevu süreçlerini dijital ortamda yönetmesini amaçlamaktadır.

Sistem; rol bazlı yetkilendirme, REST API, LINQ sorguları ve yapay zekâ destekli egzersiz önerileri gibi modern web teknolojilerini içermektedir.
